# Regional-Sales-Analysis-Dashboard---Tableau
This repository contains the Regional Sales Analysis Dashboard project, developed as part of a Tableau course-end project. The dashboard provides a dynamic and interactive tool to compare the sales performance of two selected regions side by side, empowering management with actionable insights for strategic decision-making.

***
# Project Overview
## Objective
+ Dynamically compare two selected regions (Primary and Secondary).
+ Analyze total sales, average sales per order, number of customers, orders, and products sold.
+ Identify high-performing and underperforming regions to guide strategy.

## Problem Statement
Sales performance analysis is critical for identifying trends, evaluating success, and implementing effective strategies. However, understanding and comparing regional performance can be challenging without a dynamic tool. This dashboard addresses this gap with interactive, region-specific sales insights.

***

# Methodology and workflow

The project followed a systematic approach, divided into three main phases: **Data Preparation**, **Building Charts**, and **Building Dashboards**. Below is a detailed outline of the methodology and workflow:  

## 1. Data Preparation 

This phase focused on data preparation and understanding to ensure accuracy and relevance for visualization.

+ **Collect Data**: Used the **Sample-Superstore** dataset.
+ **Connect Data**: Verified relationships between tables and ensured proper data connectivity.
+ **Build Data Model**: Organized the data into a structured format.
+ **Check Data Quality**: Reviewed the dataset for inconsistencies, missing values, and errors.
+ **Check Data Types**: Ensured fields were correctly assigned as numeric, text, or date for seamless analysis.
+ **Understand and Explore Data**: Performed an exploratory analysis to uncover patterns, trends, and potential insights.

## 2. Building Charts
The visualizations were designed to meet the analysis objectives using a clear, iterative process:

+ **Analyze Requirements and Choose Chart**: Selected appropriate charts (e.g., maps, dual-axis bar charts, line charts) based on the analysis goals.
+ **Initial Format of Sheet**: Prepared the Tableau worksheets for visualization.
+ **Create Calculated Fields and Test**: Built custom fields for key performance indicators (e.g., Average Sales Per Order, KPI Profit Avg, and KPI Sales Avg) and validated their accuracy.
+ **Build Chart**: Developed visualizations to compare and analyze regional performance.
+ **Format Chart**: Refined charts with proper formatting for clarity, readability, and aesthetics.

  ## 3. Building Dashboard
  The final phase involved assembling the dashboard and enhancing its usability:

+ **Plan the Dashboard**: Sketched layout mockups using tools like Draw.io and selected a color palette using Coolors.
+ **Create Container Structure**: Organized visualizations using Tableau containers to enable side-by-side comparisons.
+ **Put It All Together**: Assembled visualizations, KPIs, and interactive elements into the dashboard.
+ **Fix Colors**: Applied a cohesive dark theme with turquoise and yellow-orange highlights.
+ **Fix Texts**: Reviewed labels, headings, and annotations for consistency and clarity.
+ **Refine Charts**: Enhanced visualizations to improve usability and insights delivery.
+ **Fix Spacing (Inner/Outer)**: Adjusted layout spacing to maintain a clean and professional appearance.
+ **Fix Tooltips**: Customized tooltips to provide additional context for interactive exploration.
+ **Add Filters and Legends**: Included filters, legends, and parameters to enhance interactivity.
+ **Add Logo and Icons**: Integrated branding elements and navigation icons for a polished finish.
